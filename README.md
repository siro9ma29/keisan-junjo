# 計算の順じょマスター

（ ）・×÷・左から順、の計算の順序を学ぶアプリです（1ファイル・オフライン対応）。

## モード

問題は とばせません（とけたら「つぎの問題」が出ます）。

- 記号モード：レベル1〜4（問題は自動で作られます。記号をタップすると計算は自動）
- 計算モード：レベル1〜4（記号モードと同じ式で、記号をタップしたあと自分で計算します）
  - 画面上の筆算で、位ごとに数字を入力（たし算・ひき算・かけ算・わり算）
  - ひき算のくり下がりは、上の数字をタップして「10 かりる」。0 の位は、さらに左からかりてくる
  - 「くり上がり・くり下がりも 自分で書く」をOFFにすると、かりる手順は自動で書かれます
  - わり算は「たてる→かける→ひく→おろす」を表示
  - 九九ですぐ出せる計算は「あんざん」で答える（筆算に切りかえも可）
  - たし算・かけ算は「くり上がり（上に小さく）→ その位の答え」の順に入力。かけ算は1つのかけ算ごとに書いてからつぎの位へ（432×6 なら 6×2＝12 の「1」「2」→ 6×3…）
  - 2けたをかけるときの、さいごのたし算も くり上がりを書く
- 冒険モード：記号モード・計算モードの8レベルをすべてクリアすると解放
  - 4つの島（たしひきの草原／かっこの森／かけわり谷／まおうの城）を、1島「ステージ3つ＋ボス」で進む
  - 問題はすべて計算モードと同じ「順じょをえらんで、自分で計算」
  - ステージ：3問（まおうの城は2問）。全問とけばコマが進む（★もつく）
  - ボス戦：4問（まおうの城は5問・全レベルの総復習）。ハート5つ、まちがえるとボスの攻撃でハートが減る。ノーミスでとくと「かいしんの いちげき」
- 花火職人モード：はじめから使える。数と記号だけの式に（ ）をつけて、目標の数をつくる（逆問題）
  - 数を2つタップすると、そのあいだが（ ）でかこまれる。「うちあげ」で計算の順じょどおりに1ステップずつ計算して、目標の数になれば花火が上がる
  - 「（ ）なしで うちあげ」もある。レベル2・3では、（ ）が いらない問題が5問中1問まじる
  - レベル1（＋−×・数3つ）／レベル2（÷も・数3つ）／レベル3（数4つ）、各5問。★はまちがい・ヒントの合計で決まる（0回＝★★★、2回まで＝★★）
  - ★は記号・計算モードの★（24こ）とは別に数える
- 記号・計算・冒険モードでも、正しい記号をタップすると小さな花火、1問とけると打ち上げ花火が上がる

## ★とクリアの基準

ヒントを使った回数も「まちがい」と同じに数えます。

| | ★ | ★★ | ★★★ |
|---|---|---|---|
| 記号モード（10問） | 全問とく | まちがい・ヒント合わせて2回まで | ノーミス（ヒントなし）＝**クリア** |
| 計算モード（6問／レベル4は4問） | 全問とく | 順じょノーミス＋計算のまちがい・ヒント3回まで＝**クリア** | パーフェクト |

- ヘッダーに★の合計（24こ満点）と称号（みならい→ブロンズ→シルバー→ゴールド→じゅんじょマスター→でんせつのゆうしゃ）を表示
- 効果音あり（ヘッダーの🔊でオン・オフ）

## 先生用

- 問題の追加（「先生の問題」で出題、★はつかない）
- 冒険モードをすぐ使えるようにする／★の記録を消す（花火職人の★も消える）／冒険をはじめからにする

記録はその端末のブラウザに保存されます。
