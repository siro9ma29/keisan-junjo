# 計算の順じょマスター

（ ）・×÷・左から順、の計算の順序を学ぶアプリです。

- 数字モード：レベル1〜4（問題は自動で作られます）
- 計算モード：計算1〜4（数字モードと同じ式で、記号をタップしたあと自分で計算します）
  - 画面上の筆算で、位ごとに数字を入力（たし算・ひき算・かけ算・わり算）
  - ひき算のくり下がりは、上の数字をタップして「10 かりる」。0 の位は、さらに左からかりてくる
  - 「くり上がり・くり下がりも 自分で書く」をOFFにすると、かりる手順は自動で書かれます
  - わり算は「たてる→かける→ひく→おろす」を表示
  - 九九ですぐ出せる計算は「あんざん」で答える（筆算に切りかえも可）
  - 結果画面に「順じょのまちがい」と「計算のまちがい」を分けて表示
- イラストモード：イラスト1〜4（ものを組み立てたり、ならべたり、ピザを分けたりして順序を学びます）
- くふうモード：くふうA〜D（計算のきまり）
  - A いれかえる：数字をタップして入れかえ、キリのいい数を作る（交換法則）
  - B （ ）をつけかえる：記号をタップして（ ）をうつす（結合法則）
  - C わける・まとめる：同じ「×▲」をまとめる／98 を（100−2）に分けてかける（分配法則・面積図つき）
  - D ミックス・たしかめ：同じ答えになる式をえらぶ問題とA〜Cのまぜ合わせ
