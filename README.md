# 計算の順じょマスター

（ ）・×÷・左から順、の計算の順序を学ぶアプリです。

- 数字モード：レベル1〜4（問題は自動で作られます）
- イラストモード：イラスト1〜4（ものを組み立てたり、ならべたり、ピザを分けたりして順序を学びます）
- くふうモード：くふうA〜D（計算のきまり）
  - A いれかえる：数字をタップして入れかえ、キリのいい数を作る（交換法則）
  - B （ ）をつけかえる：記号をタップして（ ）をうつす（結合法則）
  - C わける・まとめる：同じ「×▲」をまとめる／98 を（100−2）に分けてかける（分配法則・面積図つき）
  - D ミックス・たしかめ：同じ答えになる式をえらぶ問題とA〜Cのまぜ合わせ
