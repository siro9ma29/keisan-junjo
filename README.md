# 計算の順じょマスター

（ ）・×÷・左から順、の計算の順序を学ぶアプリです（1ファイル・オフライン対応）。

## モード

問題は とばせません（とけたら「つぎの問題」が出ます）。

- 記号モード：レベル1〜4（問題は自動で作られます。記号をタップすると計算は自動）
- 計算モード：レベル1〜4（記号モードと同じ式で、記号をタップしたあと自分で計算します）
  - 画面上の筆算で、位ごとに数字を入力（たし算・ひき算・かけ算・わり算）
  - ひき算のくり下がりは、上の数字をタップして「10 かりる」。0 の位は、さらに左からかりてくる
  - 「くり上がり・くり下がりも 自分で書く」をOFFにすると、かりる手順は自動で書かれます
  - わり算は「わり算のひっ算アプリ」と同じ手順（たてる・かける・ひく・おろすのボタン操作はなく、手順は自動で進む）
    - 商が たたない位には「×」（商が たたない）をおす
    - たてる：わる数と わられる数の 下のけたを タップすると ゆびで かくせる（指かくし）。見当の商（かりの商）を たてる
    - かける：右の「かけ算の ひっ算」で、わる数×かりの商 を 一の位から書く（くり上がりを先に）。答えは わり算の ひっ算に うつる
    - ひく：大きすぎて ひけないときは、かりの商に線を引いて 1 へらし、かけ算から やりなおす（自動）。ひけるときは 一の位から書き、ひけない位は「10 かりる」をおす
    - おろす：つぎの位の数は 自動で おりてくる
    - 「じっくり計算」（筆算の下のチェック。はじめはON）：ONのときは 上のように かけ算の ひっ算・「10 かりる」を 書く。OFFのときは「×」は書かずに 商が たつ位から はじめ、補助計算を 出さず、かけ算・ひき算の答えを わり算の ひっ算に いきなり 一の位から書く
  - 九九ですぐ出せる計算は「あんざん」で答える（筆算に切りかえも可）
  - たし算・かけ算は「くり上がり（上に小さく）→ その位の答え」の順に入力。かけ算は1つのかけ算ごとに書いてからつぎの位へ（432×6 なら 6×2＝12 の「1」「2」→ 6×3…）
  - 2けたをかけるときの、さいごのたし算も くり上がりを書く
- 式をつくろう：文章題から 1つの式を つくる（数は自動で入り、記号だけを えらぶ）
  - 式に つかう 文は 折り返さず 横1行（はばに あわせて 文字を 小さくする）。のこりの 文（「買いました。代金は…」）は その下に出す
  - 文の すぐ下に 1行で 式が できていく。数は その数の ことばの 真下、記号の □ は「と」などの 真下。「80円の ジュース2本」は 80□2 と まとめて 出す
  - 下線の ところを見て 何算かを えらぶと、□が その記号に かわる。（ ）は 中の計算が できたときに 自動で つく → さいごに 1つの式になり、計算の順じょで 答えが 出る
  - 自分で 線を ひく問題では、まだ えらんでいない □ は 見せない（線を ひく場所が わかって しまうため）
  - 「〜円の ○○を □本」は ×、「と」は 2つを 合わせる ＋、「出して…おつり」は −
  - レベル1（a×m＋b×n、a＋b×n）／レベル2（c−(a＋b)、(a＋b)×n）／レベル3（まぜて）、各5問
  - はじめは アプリが 線を ひく。ノーミス（ヒントなし）で 5問 続けて とけると、そのレベルは「自分で 線を ひく」問題に うつる（はじめと おわりの ことばを タップ）
  - ★は 記号・計算モードの★（24こ）とは 別に 数える（保存キー junjo_shiki）。先生用ボタンで 線の ひき方を きりかえられる
- 花火大会（もとの冒険モード）：記号モード・計算モードの8レベル（＝修行）をすべてクリアすると出られる
  - 見習い花火師として、4つの会場（川べりの 夕すずみ花火／森の 神社まつり／港の 花火大会／夜空の 大花火大会）を、1会場「花火玉づくり3つ＋本番」で進む
  - 問題はすべて計算モードと同じ「順じょをえらんで、自分で計算」
  - 花火玉づくり：3問（夜空の大花火大会は2問）。全問とけば花火玉ができてコマが進む（★もつく）
  - 本番：4問（夜空の大花火大会は5問・全レベルの総復習）。1問とくごとに花火が上がり、歓声ゲージがたまる。火種5つ、まちがえると不発になって火種が減る。ノーミスでとくと「スターマイン」
  - 夜空アルバム：花火玉づくりで1つ、本番のフィナーレで1つ、花火の種類（ぼたん・きく・やなぎ…ナイアガラ・さんじゃくだま）が集まる（全16種）
  - 進みぐあいのデータは もとの冒険モードのものを そのまま引き継ぐ
- 花火工房：花火大会の画面の上にあり、花火大会が始まる前でも いつでも使える。数と記号だけの式に（ ）をつけて、注文の数をつくる（逆問題）
  - 数を2つタップすると、そのあいだが（ ）でかこまれる。「ためしうち」で計算の順じょどおりに1ステップずつ計算して、注文の数になれば花火が上がる
  - 「（ ）なしで ためしうち」もある。レベル2・3では、（ ）が いらない問題が5問中1問まじる
  - レベル1（＋−×・数3つ）／レベル2（÷も・数3つ）／レベル3（数4つ）、各5問。★はまちがい・ヒントの合計で決まる（0回＝★★★、2回まで＝★★）
  - ★★いじょうで注文をこなすと「特製玉」がもらえる（最大3こ）。本番で まちがえて火種が減ったとき、特製玉を使うと火種が1つもどる
  - 工房の★は、記号・計算モードの★（24こ）とは別に数える
- どのモードでも、正しい記号をタップすると小さな花火、1問とけると打ち上げ花火が上がる
- 導火線：式の下に導火線があり、🔥が「いま火がある場所」。正しい記号をタップすると火花が導火線を走ってその記号に火がつき、計算した答えの下に🔥がうつる（計算の順じょ＝火がとどく順番）
  - まちがえた記号は「まだ 火が とどかない！」とけむりだけ出る。ヒントでは、つぎに火がとどく記号の下の玉が光る
  - 花火工房の「ためしうち」でも、計算の順じょどおりに火花が記号をめぐる

## ★とクリアの基準

ヒントを使った回数も「まちがい」と同じに数えます。

| | ★ | ★★ | ★★★ |
|---|---|---|---|
| 記号モード（10問） | 全問とく | まちがい・ヒント合わせて2回まで | ノーミス（ヒントなし）＝**クリア** |
| 計算モード（6問／レベル4は4問） | 全問とく | 順じょノーミス＋計算のまちがい・ヒント3回まで＝**クリア** | パーフェクト |

- ヘッダーに★の合計（24こ満点）と称号（見習い→一人前→花火師→名人→じゅんじょマスター→花火大名人）を表示
- 効果音あり（ヘッダーの🔊でオン・オフ）

## 引き継ぎメモ（2026-11-06）

### 【計算順じょマスター】式をつくろうモード
- 対象・単元：4年 計算のきまり（文章題を1つの式に表す）
- できていること：
  - メニューに「📝 式をつくろう」を追加。レベル1（a×m＋b×n、a＋b×n）／レベル2（c−(a＋b)、(a＋b)×n）／レベル3（まぜて）、各5問・問題は自動生成
  - 流れ：下線の部分を見て ＋−×÷ を選ぶ → 文の真下の □ が記号に変わる → 1つの式ができる → 計算の順じょで1行ずつ計算して答え
  - ノーミス（ヒントなし）5問連続で、そのレベルは「自分で線を引く」問題に移行（はじめと終わりの言葉をタップ）
  - ヒント2段階（言葉で伝える → 線や記号を光らせる）。★はまちがい・ヒントの合計で決まる（記号・計算モードの★24こには入れない）
- 決めた仕様（理由も一言）：
  - 数は自動で入り、記号だけを選ぶ（何算かを考えることに集中させるため）
  - ＋は「と」に注目させる（「代金」という言葉に頼らせないため）
  - （ ）がいるかは選ばせず、自動でつける（立式に集中させるため）。式ができたときに、（ ）がつく・いらない理由を一言で出す
  - 式に使う文は折り返さず横1行。数はその言葉の真下、□は「と」の真下に出す（文がそのまま式に変わっていくのを実感させるため）
  - おつりの文は「500円出して、〜と〜を買いました」の順（1行に収め、式 500−(a＋b) の数の並びとそろえる）
  - 自分で線を引く問題では、選んでいない □ は見せない（線を引く場所が分かってしまうため）
  - 「1こ」「1さつ」の品に線を引いたときは、まちがいに数えず「かけ算にしなくていいよ」と伝える
  - 5問連続の数え方はレベルごと。先生用ボタンで、線をアプリが引くか子どもが引くかを切りかえられる
- 未解決・次にやること：
  - 残りの文（「買いました。代金は…」）の出し方（今は式の下。問題文全体を上に出す案もある）
  - スマホの幅では1行めの文字が13px前後まで小さくなる（タブレットは30px）
  - 答えを子ども自身が計算する流れ（計算モードの筆算）につなぐか
  - ×と−、÷がまじる問題を足すか
